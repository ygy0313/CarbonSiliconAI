# 2026-10-22 · 三层架构重构与经验资产层

## 背景

用户提出新一轮产品思路：不做「意识上传」，做**用户经验的硅基化封装器**。
三层：用户专属 Agent（主）/ 服务型 Agent 集群（从）/ 小程序+H5（入口）。
记忆分三层：原始（密文只追加）/ 结构化（实体事件）/ **经验（可执行规则，资产化核心）**。
新增需求：后台建议 C++。

## 本轮落地

### 1. C++ 计算内核（core/，端口 8788，仅监听本机）

- C++17 **零外部依赖**：自写 minijson（header-only）+ POSIX socket 线程池服务。
  `cd core && make` 一行编译；`./bin/qjz-core selftest` 17 项自检；`bench` 内置压测。
- 两个端点（稳定契约）：`POST /v1/experience/rank`（评分排序）、`POST /v1/reflect/mine`（反思挖掘）。
- 算法：相关性闸门（tag/scene/intent/bigram 余弦取 max，<0.15 丢弃）× 加权质量分
  （有效 0.45 + 新鲜 0.2 + 样本 0.2 + 命中率 0.15，拉普拉斯平滑 (followed+1)/(applied+2)）。
- **压测关键结论（同机同负载）**：C++ 0.22/1.22/5.8 ms（200/1000/5000 条），
  JS 镜像 0.29/1.46/7.8 ms —— **V8 只慢 25-30%，不是数量级**。
  C++ 的真正价值：① 把 CPU 密集批处理移出 Node 单线程事件循环；② 协议稳定可独立扩容；
  ③ 纯函数零依赖可移植。**以此否决了「全后端 C++ 重写」**（负收益，写进 docs/08）。
- 优化教训：初版 12.7ms/5000 条，因每条都拼字符串建两遍 bigram。改为查询只建一次
  bigram + 已有高匹配时跳过文本相似度（数学等价的 early-exit）→ 5.8ms。

### 2. 经验资产层（本轮核心）

- `domain/experience.js`：schema + 四条硬规则（必须溯源/渐进更新/只降权不删除/双环锁标准）。
- 有效性更新（单环）：奏效 = +(1-c)*0.18，失效 = ×0.78。一次意外打不穿长期规则。
- `reflect.service.js`：从 invocation+feedback 还原「情境-行动-结果」，调内核挖掘，
  按 signature 去重；更新已存在经验时**刷新规则里的计数但不重置评分**。
- `experience.service.js`：检索（内核 rank）/ 应用回写 / 手写（0.7 权重）/ 资产盘点 + nextAction。
- **双环约束**：criteria 带版本号，`POST /criteria` 无 `confirm:true` 直接拒，改动进审计。
- 隔离：跨人读经验返回 **404 而非 403**（403 泄漏存在性）。
- **经验参与仲裁而非贴标签**（关键产品决策）：反思产出的规则指向具体选项，
  下次编排时该选项若在候选中会被提到第一位并标注「你以前选过」。
  只提升已存在候选，不凭空造卡片。首版把经验挂在结果后面当注解，自评为假闭环，推翻重做。
- 导出升级：`qijuzhu/v1` payload 新增 experiences + criteria，导入恢复经验（id 重新生成）。
- H5 新增「经验」页：资产总览 / 待确认-可用-休眠分组 / 立即提炼 / 标准确认编辑。

### 3. 降级与同构（红线）

- `src/core/fallback.js`：与 C++ 逐项对齐的 JS 镜像。内核停机实测：编排照跑，engine=js。
- check-experience.js 里的**同构断言**（两实现同一输入必须同序同分）抓出过 JS 镜像的
  真 bug：evidence 数组参与数值加法 → NaN → score=null → 排序静默失效。
  结论：**双实现互为对方的测试**，这个模式值得保留。

## 踩坑

- **shell grep 在本机会对某些模式静默返回空**（grep "home" 明明存在却无结果），
  用 Grep 工具（ripgrep）才对。老坑再现，再次确认。
- headless Chrome `--window-size=430` 截图出现右侧裁切，iframe 实测 scrollWidth=430
  无溢出 —— 是截图视口伪差，不是布局 bug。**iframe 实测是判据，截图不是**。
- 反思规则文本里的卡片标题要去副标题（`拌汤（洋芋疙瘩汤）`→`拌汤`），
  否则规则不可读且与下次候选对不上。
- 内核是长驻进程，**改完 C++ 必须重启 8788**，否则跑的是旧二进制（本次就踩了：
  改了 sceneLabel 中文映射，线上还在吐「solo 场景」）。

## 产品判断（写给下一轮的自己）

- 经验资产成立与否只有一个验证指标：**用户是否在两周后回来查看自己的经验资产，
  并在新情境中调用它**。资产页的 nextAction 就是冲着这个行为设计的。
- 「数字永生」在哲学上不成立（意识=不可重复的事件历史），所以产品卖的不是复制人，
  是**这个人特有轨迹的产物** —— 架构上按人隔离、不可迁移，既是隐私也是差异化。
