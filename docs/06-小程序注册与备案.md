# 小程序注册与备案：具体操作流程

> 先说结论，免得白跑：**你要办的是两件独立的备案** ——
> ① 域名的 ICP 备案（在阿里云办，因为服务器在那）；② 小程序本身的备案（在微信公众平台办）。
> 两件事的主体必须是同一个（都是你个人，或都是你的个体户）。
> 全程线上，总周期约 **2-4 周**，费用 **0 元**（个人主体无需微信认证费）。

## 〇、先做一个关键决策：个人主体，还是个体工商户？

| | 个人主体 | 个体工商户/企业主体 |
|---|---|---|
| 注册成本 | 0 元，当天可用 | 办执照约 0-200 元，3-7 天 |
| 微信支付 | ❌ 不支持 | ✅ 可开通（需另外认证 300 元/年） |
| 可选类目 | 仅工具、生活记录等少数 | 覆盖餐饮、电商、商业服务 |
| 获取用户手机号 | ❌ | ✅ |
| 流量主广告 | 受限 | ✅ |
| 备案难度 | 简单 | 略高（多营业执照材料） |

这个产品要接「组局订金、茶歇代购、红酒带货」，迟早要支付。
**建议直接注册个体工商户**（银川线上可办，住址申报承诺制），一步到位。
个人主体先把流程跑通也可以，之后主体不能直接升级、只能重新注册 —— 这是最大的坑。

---

## 一、注册小程序账号（约 30 分钟）

1. 准备一个**没注册过任何微信公众平台的邮箱**（QQ 邮箱可以，前提是没绑定过公众号/小程序）
2. 打开 <https://mp.weixin.qq.com> → 立即注册 → 选「小程序」
3. 邮箱验证 → 主体类型选择（个人 / 个体工商户）→ 主体信息登记
   - 个人：身份证正反面 + 人脸识别 + 管理员微信
   - 个体户：营业执照 + 法人身份证 + 对公/法人微信验证
4. 填小程序名称（**建议直接用「起居注」**，先查重）、简称、类目
5. 完成 → 在「设置 → 基本设置」里拿到 **AppID**

> ⚠️ 名称一旦发布就占用：小程序名称全网唯一。「起居注」三个字被占的概率不低，
> 备选：起居注笔记 / 起居手帐 / 一纸起居。查重在注册第 4 步就能看到。

## 二、域名 ICP 备案（在阿里云，约 7-20 个工作日）

前提：域名在阿里云（或已转入），ECS **包月 3 个月以上**（有备案服务名额）。

1. **买域名**：阿里云万网，`.com`/`.cn` 都行（`.top`/`.xyz` 首年便宜，但部分管局对廉价后缀审核更严，建议 `.com`，约 60-80 元/年）
2. **域名实名认证**：注册人必须与备案主体一致（个人备案 → 域名注册人是你本人）
3. 阿里云控制台 → 「ICP 备案」→ 开始备案
   - 填主体信息（个人：身份证；个体户：营业执照 + 法人身份证）
   - 填网站信息：网站名称建议与小程序相关，内容选「博客/个人空间」或「企业官网」；**不要出现「经营」「交易」字样**（个人备案）
   - 服务器：选你的 ECS（消耗一个备案服务号）
   - 网站负责人人脸核验（App 上做）
4. 阿里云初审：1-2 个工作日，会打电话核实，说法要跟填的一致
5. 工信部短信核验：**12381 发来的短信，24 小时内必须点链接完成核验**，超时自动驳回（最常见的失败原因）
6. 管局终审：5-20 个工作日（宁夏通常较快）
7. 拿到备案号（如 `宁ICP备2026XXXXXX号`）→ **必须展示在 H5 页脚**（`web/index.html` 加一行）

## 三、小程序备案（在微信公众平台，约 7-20 个工作日）

2023 年 9 月起，新注册小程序不备案不能上线。

1. mp.weixin.qq.com 登录小程序后台 → 首页通常有「小程序备案」入口（或 设置 → 基本设置 → 小程序备案）
2. 填写：主体信息（与 ICP 备案一致）、负责人信息、小程序信息（名称、AppID、服务类目）
3. 平台初审：1-2 个工作日
4. 又一次 12381 短信核验：同样 **24 小时内**
5. 管局审核：通过后自动生成小程序备案号
6. 备案通过前**不能提交代码审核**，先别急着开发布包

## 四、两边都下来之后

1. 微信后台「开发 → 开发设置 → 服务器域名」：
   - request 合法域名：`https://你的域名`
   - 下载校验文件 `xxx.txt`，放到 ECS 的 Nginx 静态目录（或让后端加一条路由返回它）
2. `miniprogram/utils/api.js` 的 BASE 改成 `https://你的域名`
3. `miniprogram/project.config.json` 的 `appid` 换成正式 AppID
4. H5 页脚加备案号（微信审核会看）
5. 提交代码审核 → 发布

## 五、总账单

| 项目 | 费用 |
|---|---|
| 小程序注册 | 0 |
| 个人主体认证 | 0（个人无需认证） |
| 个体户认证（可选） | 300 元/年 |
| 域名 | 60-80 元/年 |
| ECS | 已有 |
| HTTPS 证书 | 0（Let's Encrypt） |
| 备案 | 0 |
| **合计（个人主体）** | **约 70 元/年** |

## 六、高频驳回原因（提前避开）

1. **12381 短信超时未核验** —— 提交后两天内盯紧手机
2. **域名注册人与备案主体不一致** —— 用谁的身份备案，域名就用谁的名字注册
3. 个人备案的网站名称带「商城」「服务」等经营性词汇
4. 证件照片反光、缺角、带水印
5. 管局电话回访时说的用途与填报不一致 —— 提前想好一句话说法，照着填的念
