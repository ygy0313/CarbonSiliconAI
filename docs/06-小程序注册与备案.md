# 主体注册与正式 AppID 落地手册（2026 版）

> **这一版的口径**：先把主体单独注册掉，拿到正式 AppID，再谈上线。
> 三件事是**串行**的，不能并行抢跑：**办执照 → 注册小程序（认证）→ 两个备案**。
>
> 全程线上，人不用跑窗口。**费用 300 元/年（微信认证）+ 域名 60~80 元/年**，
> 备案本身 0 元。周期：执照 1~3 天，认证 1~3 天，备案 2~4 周。

---

## 〇、结论先行

| 步骤 | 办什么 | 在哪办 | 周期 | 花费 | 拿到什么 |
|---|---|---|---|---|---|
| 1 | 个体工商户设立登记 | 「我的宁夏」App / 宁夏政务服务网 | 1~3 天（多数即时办结） | 0 元 | 电子营业执照 + 统一社会信用代码 |
| 2 | 注册小程序 + 微信认证 | <https://mp.weixin.qq.com> | 当天注册，认证 1~3 天 | **300 元/年** | **AppID**（+ AppSecret） |
| 3 | 域名 ICP 备案 | 阿里云（服务器所在） | 7~20 个工作日 | 0 元 | `宁ICP备xxxxxxx号` |
| 4 | 小程序备案 | 微信公众平台后台 | 初审 1~2 天 + 管局 1~20 工作日 | 0 元 | 小程序备案号 |

**为什么必须是个体工商户**：个人主体不能申请「深度合成」类目、不能开微信支付、不能拿用户手机号。
而且主体**一旦选定不能升级**，只能注销重注册 —— 这是最贵的坑，不要用个人主体试水。

## 一、第一步：办个体工商户（银川，掌上办）

银川已全面推行「全程网办、无纸化」，个体工商户设立可以完全在手机上办完，电子签名、电子执照即时下发。

**入口（二选一）**
- 「我的宁夏」App → 营业执照「掌上登记」专区 → 个体工商户设立
- 宁夏政务服务网 <https://zwfw.nx.gov.cn> → 个体工商户设立登记注册（五星级全程网办事项）

**材料**
- 经营者身份证（正反面，拍照）
- 经营场所：自有房产用房产证；租房用租赁合同 + 房东房产证复印件。
  没有商用场地也可用**住所申报承诺制**（住宅改经营），按页面提示勾选承诺书 —— 这一步各地口径不同，被驳回就改成租赁合同
- 手机号（本人实名）
- 名称（见下）
- 经营范围（见下，**这段最影响后面小程序类目审核**）

**名称（先想 3 个，按顺序试）**

格式：`银川市<区>+ 字号 + 行业 + 组织形式`

| 顺序 | 备选 |
|---|---|
| 1 | 银川市西夏区起居注信息技术工作室 |
| 2 | 银川市金凤区执笔信息技术工作室 |
| 3 | 银川市兴庆区一纸起居信息服务中心 |

> 字号避免「酒」「商贸」「文化传媒」——那会把主体属性和产品（工具类）绑错，
> 后面申请「工具-效率」类目时容易被要求补资质。卖酒是后来的事，可以后期做经营范围变更。

**经营范围模板（照抄，按顺序写全）**

```
软件开发；信息技术咨询服务；信息系统集成服务；数据处理和存储支持服务；
互联网数据服务；数字内容制作服务（不含出版发行）；专业设计服务；
平面设计；广告设计、代理；企业管理咨询；市场营销策划。
（依法须经批准的项目，经相关部门批准后方可开展经营活动）
```

> 关键：一定要有 **「软件开发」「信息技术咨询服务」「互联网数据服务」**。
> 小程序类目审核会看营业执照经营范围与实际功能是否匹配，缺这三项，
> 「工具-效率」类目容易被判定为「经营范围不符」。
>
> 将来要在小程序里直接卖酒，再加：`食品销售（仅销售预包装食品）`。
> 注意：**仅销售预包装食品是「备案」不是「许可」**（《食品经营许可和备案管理办法》），
> 比办《食品经营许可证》轻得多；酒属于预包装食品。现在不用加。

**办完之后**：下载电子营业执照（PDF/图片），记下**统一社会信用代码**（18 位）。这就是后面所有环节的主体凭证。

## 二、第二步：注册小程序，拿 AppID（当天）

1. **备一个从没注册过微信公众平台的邮箱**（QQ 邮箱可以，但必须没绑过公众号/小程序/开放平台）。
   一个邮箱只能注册一个小程序，被占用只能换。
2. <https://mp.weixin.qq.com> → 立即注册 → 选「小程序」
3. 填邮箱 → 收激活邮件 → 设密码 → 激活
4. **主体类型选「企业（个体工商户）」**（页面上的原话就是这个），填：
   - 名称：营业执照上的名称
   - 统一社会信用代码
   - 经营者姓名 + 身份证号
   - 管理员信息（可以是经营者本人，也可以是你）
5. **主体验证方式（二选一）**
   - **法人/经营者微信扫码验证**：当场通过，推荐
   - 对公账户打款验证：免费，但要 1~3 个工作日，且个体户还得先开对公户 —— 不划算
6. **微信认证：300 元/年**（审核服务费，认证有效期 1 年，到期要续，否则支付/手机号等能力会掉）
   - 入口：小程序后台 → 设置 → 微信认证
   - 认证前部分功能不可用，**认证通过才算真正可用**
7. **拿 AppID**：后台 → 开发 → 开发管理 → 开发设置 → **AppID(小程序ID)** 和 **AppSecret**
   - AppID 可以公开，AppSecret **只出现一次**，丢了只能重置；不要进 git

**小程序名称**：全网唯一，先查重。
- 首选「起居注」；备选：`起居注笔记` / `一纸起居` / `执笔起居注`
- 名称不得含「最」「第一」「官方」等极限词，也不要带「运势」「算命」类字眼

## 三、第三步：服务类目（最容易踩坑，也最容易白干）

### 3.1 首版按「无 AI 生成」提审

微信的规则很硬：**只要小程序里出现 AI 生成的文本（AI 问答 / AI 创作），就必须选「深度合成-AI问答」类目**，
而该类目资质二选一：

| 路径 | 需要什么 | 现实难度 |
|---|---|---|
| 自研 | 主体自己的《互联网信息服务算法备案》（生成合成类） | 需要算法备案，周期以月计 |
| 用第三方模型 | 模型方的算法备案 + 双方盖章合作协议（写明算法名称/备案编号） | 要跟模型厂商签协议 |

**关键判断**：本项目后端 `llm.enabled` 默认 **false**，编排全部由规则引擎 + 本地经验资产完成，
**天然不触发「深度合成」类目**。所以：

- **首版提审：不启用 LLM**，类目走「工具-效率」（备选「生活服务-其他」）
- 第二阶段再接模型：优先选**已备案的国内厂商**（混元/DeepSeek/通义等），走「第三方技术」路径，
  同时在小程序内给 AI 生成内容加显著标注「AI 生成」

> 这条不是省钱，是省时间：算法备案 + 合作协议能拖掉一两个月，
> 而你的第一验证指标是「用户两周后会不会回来」。

### 3.2 两条必须自查的红线

1. **占卜/算命内容 = 审核违规**。干支、五行只能落在「传统文化 / 节气 / 饮食口味建议」，
   不能出现「运势」「吉凶」「财运」「姻缘」。当前代码与文案已按此写（全仓扫描 0 命中），
   但**提审前要再扫一遍 UI 文案**，尤其是自己临时加的提示语。
2. **酒类**：站内只做推荐、跳转外部店铺下单 → 不需要食品类目；
   一旦在小程序内下单收款 → 需 `食品销售（仅销售预包装食品）` 备案 + 「商家自营-食品饮料」类目 + 微信支付。

## 四、第四步：两个备案（主体必须完全一致）

| | 域名 ICP 备案 | 小程序备案 |
|---|---|---|
| 在哪 | 阿里云控制台 → ICP 备案 | 微信公众平台 → 设置 → 小程序备案 |
| 前提 | 域名在阿里云 + ECS 包月 ≥3 个月（有备案服务号） | 小程序已认证 |
| 主体 | 营业执照主体 | **同一营业执照主体** |
| 初审 | 阿里云 1~2 个工作日（会电话核实） | 平台 1~2 个工作日 |
| 管局 | 5~20 个工作日（宁夏通常较快） | 1~20 个工作日 |
| 关键动作 | **12381 短信 24 小时内完成核验**，超时自动驳回 | 同样盯紧 12381 短信 |
| 产出 | `宁ICP备xxxxxxx号` → 放 H5 页脚 | 小程序备案号 |

**最容易失败的三个点**
1. 12381 短信超时没点（占驳回原因一半以上）
2. 域名注册人是个人、备案主体是个体户（主体不一致，直接驳）
3. 管局电话回访时说的用途和填报不一致 —— 提前定一句话口径：
   「做一个帮个人记录生活信息、提供生活建议的工具类小程序，不涉及交易」

**域名**：`.com` 优先（约 60~80 元/年），廉价后缀部分管局审得更细。
域名实名认证的持有人**必须与备案主体一致**（个体户 → 持有人写营业执照上的名称）。

## 五、拿到 AppID 之后（代码侧 3 分钟）

```bash
# 1. 换 AppID（会校验格式，拒绝 touristappid）
node miniprogram/scripts/set-appid.js wx1234567890abcdef

# 2. 改后端地址（拿到域名之后）
#    miniprogram/utils/api.js → BASE = 'https://你的域名'

# 3. 微信后台 → 开发 → 开发设置 → 服务器域名
#    request 合法域名：https://你的域名
#    下载校验文件放到 ECS 静态目录（或后端加一条路由返回）

# 4. H5 页脚加备案号（审核会看）
#    web/index.html
```

> ⚠️ AppSecret 不要写进任何前端代码或 git；只放在服务端环境变量。
