# 硅基记忆体 · 交互设计

> 版本 v0.1 ｜ 对应 `miniprogram/` 六个页面

## 一、三条设计原则

**1. 过程要可见，结论要克制。**
用户点完发送后，先看到的是「它在干什么」（识别意图、载入档案、解析依赖、四个服务并行），然后才是结论。这一秒半的等待不是加载动画，是建立信任的过程——让他知道结果不是随机蹦出来的。

**2. 每个推荐都要能被追问。**
卡片上永远有一行「为什么」和一行「依据」。如果一条建议说不出理由，就不该出现。

**3. 修正比输入省力。**
不要求用户「完善档案」，只要求他在看到不对的东西时点一下。所以档案页的每一条事实都可点即改，「不要这个」会顺手问一句为什么。

## 二、信息架构

```
                    ┌─ 硅基体（首页 · tab）
                    │   完整度 / 它怎么理解你 / 快捷意图 / 最近记忆
                    │
                    ├─ 说一句（chat）
  硅基记忆体 ────────┤   输入 → 编排轨迹 → 结果卡 → 反馈
                    │        └→ 方案详情（plan）
                    │             时间线 / 由谁提供 / 待办 / 定下来
                    │
                    ├─ 记录（tab）
                    │   写字 → 存 → 它理解成了什么 / 改了哪些事实
                    │
                    ├─ 档案（tab）
                    │   冲突裁决 / 12 维度事实 / 记忆流 / 服务地址
                    │
                    └─ 服务市场
                        7 个服务 / 依赖关系 / 接入说明
```

再去调对应的人和服务。

**编排过程中**（这是产品的关键三秒）：

```

### 4. 记录页

```
今天发生了什么
随便写。它会把这句话拆成事实和记忆。

┌─────────────────────────────┐
│ 中午一个人吃了羊肉面，晚上胃  │
│ 有点胀                       │
└─────────────────────────────┘
(胃不舒服) (一个人) (和朋友) …

[        存进档案         ]

它的理解                72% 完整度
┌─────────────────────────────┐
│ 午餐，一个人，胃敏感          │
│ #胃敏感                      │
└─────────────────────────────┘

改动了这些事实
┌─────────────────────────────┐
│ 肠胃    偏敏感 → 偏敏感  [确认]│

关键：**存完立刻告诉用户「这句话改变了什么」**。如果什么都不变，也要说清楚（「已确认」）。否则用户会觉得记录没有意义。

## 五、交互细节

| 场景 | 处理 |
|---|---|
| **编排中** | 轨迹逐条浮现 140ms/条；底部按钮变「…」不可重复提交 |
| **单个 agent 失败** | 该条轨迹标红，其余结果照常出，不整页报错 |
| **后端连不上** | 自动降级到内置演示数据，顶部一行小字说明「离线演示」 |
| **意图识别不出** | 不硬猜，回「这个需求还没有对应的服务」+ 列出可用意图 |
| **推荐为空** | 说明原因（「这个人数没有合适的本」）而不是空白 |
| **反馈** | 采纳 → toast「记下了」；否决 → 弹原因选择（太辣/太贵/不舒服/太远/不想） |
| **冲突** | 只在「两个值都可信且不一致」时出现，不频繁打扰 |
| **空档案** | 首页不显示假数据，写「你的硅基体还是一张白纸」 |

## 六、视觉规范

| 项 | 值 | 用途 |
|---|---|---|
| 底色 | `#0B0F14` | 硅基的冷 |
| 卡面 | `#141B23` / `#1A232D` | 层次 |
| 主色 | `#4ADE80` 绿 | 生命、确认、主推 |
| 辅色 | `#F5B942` 琥珀 | 方案、提醒、宜味 |
| 主文字 | `#E8EDF2` | — |
| 次文字 | `#8A9AAB` | 说明 |
| 弱文字 | `#5C6B7A` | 元信息 |

字阶：52 / 36 / 30 / 28 / 26 / 22 rpx。
圆角：卡片 20rpx，按钮 16rpx，标签 8rpx，chip 999rpx。

**为什么是深色**：这是一个「关于你自己」的产品，深色让内容（记忆、理由、结论）成为唯一亮的东西。浅色底会让卡片结构比内容更抢眼。
