### 0 元路径的边界（必须说清楚）

1. **只能在开发者工具 / 真机调试里跑。** 手机预览需要手机和电脑同一局域网，且需在「档案 → 开发设置」里把服务地址改成电脑的局域网 IP（如 `http://192.168.1.10:8787`）。
2. **别人用不了。** 一旦要分享给第二个人，就必须过域名 + HTTPS + 备案这一关。
3. **小程序「体验版」也需要配置合法域名。** 只有「开发版」可以绕过域名校验。

## 三、三档方案对比

### A 档：0 元（当前）

```
小程序(个人) ──局域网 HTTP──▶ 本地 Node ──▶ JSON 文件
                                  │
                                  └─▶ Open-Meteo（免密钥）
```

适用：自己验证产品逻辑、录 demo 视频、给投资人演示。

### B 档：约 0-100 元/年（内测版）

## 四、LLM 成本模型

这是唯一会随用户量线性增长的部分，必须算清楚。

**单次编排的 token 消耗**（实测结构估算）：

| 环节 | 输入 | 输出 |
|---|---|---|
| 记忆抽取（可选） | 约 300 | 约 150 |
| 表达润色（可选） | 约 800（档案摘要 + 意图 + 结果） | 约 300 |
| **合计** | **约 1100** | **约 450** |

**各平台单价对比**：

| 平台 | 输入（元/百万 token） | 输出（元/百万 token） | 单次成本 | 说明 |
|---|---|---|---|---|
| 智谱 GLM-4-Flash | **0** | **0** | **0 元** | 长期免费档，限流约 30 QPS |
| 火山豆包 | 0（每日 200 万额度内） | 0 | **0 元** | 需手动开通模型 |
| 百度 ERNIE-Speed | 0 | 0 | **0 元** | 需实名 |
| DeepSeek-chat | 约 1 | 约 2 | 约 0.002 元 | 稳定、便宜、质量好 |
| GPT-4o-mini | 约 1.1 | 约 4.4 | 约 0.003 元 | 需海外支付 |

**规模测算**（按 DeepSeek 价格，即「免费额度用完后的兜底成本」）：

| 规模 | 调用量/月 | 全量走 LLM | 仅 30% 复杂意图走 LLM |
|---|---|---|---|
| 自己用 | 100 次 | 0.2 元 | 0.06 元 |
| 30 人内测 | 3,000 次 | 6 元 | 1.8 元 |
| 1,000 人 | 90,000 次 | 180 元 | 54 元 |
| 10,000 人 | 900,000 次 | 1,800 元 | 540 元 |

**结论**：LLM 不是成本大头。10 万次调用才 180 元。

真正的成本陷阱是**全量走 LLM**。所以架构上把 LLM 设计成「可选增强」而不是「必经链路」，不只是为了 0 元跑通，也是为了 10 倍量级时成本不失控。

## 五、成本优化策略（按性价比排序）

| 策略 | 省什么 | 预计效果 |
|---|---|---|
| **规则引擎兜底** | LLM 调用 | 意图明确时完全不调模型，省 60-70% |
| **意图置信度路由** | LLM 调用 | 置信度 > 0.75 不调模型润色 |
| **结果缓存** | 全部 | 同一人 + 同一意图 + 档案指纹未变 → 直接复用，缓存 TTL 30 分钟 |
| **免费额度轮换** | LLM 调用 | GLM 主 + 火山备 + 千帆兜底，三家免费档月均可用 8000 万 token |
| **云函数替代服务器** | 服务器 | 内测期 0 元，冷启动代价 1-3 秒 |
| **本地模型** | LLM 调用 | Mac 上跑 Ollama + qwen2.5:3b，完全免费，响应 1-3 秒，质量够做抽取 |
| **图片压缩后再上传** | 存储/带宽 | 复用「给您请安」的压图逻辑 |

## 六、什么时候必须花钱

按优先级：

1. **要让第二个人用** → 域名 + 服务器（或云函数）+ 备案。这是硬门槛，绕不过。
2. **要上「体验版/正式版」** → 合法域名 + HTTPS + 备案完成。开发版可以绕过，但体验版不行。
3. **用户超过 100 人** → 本地 JSON 会开始吃力（并发写、查询），需要换 SQLite / Postgres。
4. **要做支付/电商（红酒）** → 企业主体认证 300 元/年 + 微信支付商户号（免费但有费率 0.6%）。
5. **要做语音输入** → 语音识别 API（微信同声传译插件免费；云厂商约 1.5 元/千次）。

## 七、一句话建议

**先用 0 元把这套流程在你自己的手机上跑一周。** 每天记三条、问两次。一周后如果「它真的开始懂你了」这个感觉成立，再花 99 元买台轻量服务器 + 9 元买个域名，把它变成可以给朋友看的东西。

在感觉成立之前，一分钱都不该花。这个产品的全部风险不在技术成本，在于「人愿不愿意持续记录」——而这件事只能用一周的真实使用来验证。
