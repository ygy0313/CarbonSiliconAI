# 上线检查清单：从「本地能跑」到「别人能用」

> 按顺序过。每一项都写了「不做会怎样」，方便你排优先级。
> 标 🔴 的不做就上不了线，标 🟡 的可以上线后补。
>
> **先跑一遍自动自检**：`node miniprogram/scripts/preflight.js`
> 它会扫 AppID、后端地址、占卜类禁词、隐私入口、LLM 开关、模板体检，有 ✗ 就是硬拦。
> 主体与 AppID 的完整办流程见 `06-小程序注册与备案.md`。

## 一、账号与资质 🔴

- [ ] 注册个体工商户（银川「我的宁夏」App 掌上登记，1-3 天，0 元）
- [ ] 注册正式小程序账号，主体选「企业（个体工商户）」，微信认证 300 元/年
- [ ] 拿到正式 AppID：`node miniprogram/scripts/set-appid.js wx…`（脚本会校验格式并给出后续两步）
- [ ] 完成域名 ICP 备案（阿里云，约 7-20 工作日）
- [ ] 完成小程序备案（微信公众平台，约 7-20 工作日）
- [ ] 选择服务类目：
  - 个体户主体：首版选 `工具 > 效率`（备选 `生活服务 > 生活娱乐`）
  - **首版不启用 LLM**，否则要「深度合成-AI问答」类目 + 算法备案（个人主体不可申请）
  - **不要选「剧本杀/桌游」相关特殊类目**（部分平台要求前置审批）

## 二、服务端 🔴

- [ ] ECS 部署完成（见 `05-部署阿里云ECS.md`）
- [ ] `QJZ_PASSPHRASE` 已设置为强口令，并**另存到密码管理器**
  - 不设也能跑（自动用本地密钥文件），但换服务器/重装后历史原文解不开
- [ ] `SEED_DEMO=false`（生产不造演示数据）
- [ ] HTTPS 证书配好，`curl https://你的域名/health` 返回 ok
- [ ] `/api/dev/reset` 在生产已被禁用（代码已做，`NODE_ENV=production` 即可）
- [ ] 数据备份 cron 已配置
- [ ] 微信后台「服务器域名」已加你的域名

## 三、小程序端 🔴

- [ ] `project.config.json` 换成正式 AppID（用 `set-appid.js`，别手改）
- [ ] `utils/api.js` 的 BASE 改成线上 HTTPS 地址
- [ ] 真机测试完整流程：记录 → 问事 → 方案 → 反馈
- [x] **隐私政策 / 用户协议**有独立页面且能点开
  - 正文唯一来源：`server/src/domain/legal.js`（H5 `/legal/privacy`、`/legal/terms` 直出，小程序 `pages/legal` 拉同一份接口）
  - 首次使用有同意层：版本号不对齐就弹，未同意不写数据（`app.guardLegal()` 拦写入入口）
  - 回归：`check-legal.js` 73 项；提审自检：`preflight.js`「合规入口」段
  - 待办：运营者名称是占位，执照下来后设 `QJZ_OPERATOR_NAME` 环境变量覆盖
- [ ] **用户隐私保护指引**（mp 后台「设置 → 服务内容声明 → 用户隐私保护指引」）
  - 必须声明：不收集手机号/位置；收集「你主动输入的文字记录」用于生成推荐
  - 这个不填，`wx.login` 之外的多数接口直接被拦 —— 这是近期最容易被忽略的一项
- [ ] 小程序内容安全：
  - 用户输入的文字如果会被展示给其他用户，接 `security.msgSecCheck`
  - 当前是纯单人使用（数据不展示给第二个人），可先不接，多人前必须接
- [ ] 页面里不出现测试数据（`p_owner` 演示档案只在 `SEED_DEMO=true` 时生成）

## 四、H5 端 🟡

- [ ] 页脚加 ICP 备案号（链到 beian.miit.gov.cn）
- [ ] 手机浏览器实测：首页 / 问事 / 档案 / 授权 四页
- [ ] （可选）加一个极简统计（自建计数即可，别上第三方统计——与「数据留在用户手里」的定位矛盾）

## 五、内容与体验 🟡

- [ ] 小程序简介、H5 meta description 里写清楚「数据存在你自己的服务器，可随时导出带走」
- [ ] 首次进入引导：三句话讲明白「记一笔 → 问一句 → 给你一个能照着做的安排」
- [ ] 入局问答（12 题）放在首次使用的动线里，而不是藏在档案页

## 六、发布

1. 开发者工具 → 上传 → 填版本号与备注
2. mp 后台「版本管理」→ 提交审核
   - 审核备注里写清楚：这是个人生活记录工具，数据仅用户本人可见，无社交/UGC 公开功能
   - 提供测试账号说明（个人工具类通常需要录一段功能演示视频）
3. 审核通过 → 全量发布
4. 发布后第一周盯：mp 后台「统计 → 性能」+ 服务器 `journalctl -u qijuzhu`

## 七、上线后第一周的目标

不是拉新，是**验证留存**：你自己每天记 3 条、问 2 次，连续 7 天。
第七天回答一个问题：**「它是不是比第一天更懂我」**。
成立 → 花 70 元/年买域名上线给别人；不成立 → 产品问题在记录意愿，不在技术。
